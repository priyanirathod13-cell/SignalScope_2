# SignalScope Dataset Documentation

## 1. Dataset Overview & Provenance
* **Dataset Name**: GenImage Benchmark Development Subset
* **Source Repository**: Hugging Face [`jhutter2/281_Genimage`](https://huggingface.co/datasets/jhutter2/281_Genimage)
* **Underlying Benchmark**: *GenImage: A Million-Scale Dataset for Detecting AI-Generated Image* (NeurIPS 2023 / IEEE TPAMI).
* **Licensing**:
  - Dataset Subset: MIT License
  - Upstream Benchmark: Creative Commons Attribution-NonCommercial-ShareAlike 4.0 (CC-BY-NC-SA 4.0)

## 2. Sample Inventory & Class Distribution
The dataset is partitioned into balanced binary classes for authentic vs. synthetic image classification:

| Class | Count | Description |
| :--- | :--- | :--- |
| **Real Photography (0)** | 2,842 | Authentic natural photographic captures from the ImageNet-1K benchmark |
| **AI-Generated / Synthetic (1)** | 2,922 | Images generated by modern diffusion models (Stable Diffusion v1.5, Wukong, ADM) |
| **Total Verified Images** | **5,764** | Uncorrupted, validated RGB images (256x256 nominal resolution) |

### Generative Architecture Breakdown
* **Stable Diffusion v1.5**: 996 images (Latent Diffusion text-to-image)
* **ADM (Ablated Diffusion Model)**: 968 images (Guided pixel-space diffusion)
* **Wukong Diffusion**: 958 images (Large-scale multilingual diffusion)
* **Real ImageNet**: 2,842 images (Natural camera capture)

## 3. Data Cleansing & Validation Pipeline
1. **Integrity Audit**: Each file was inspected with Pillow (`verify()` and decode). 19 corrupt/empty upstream archives were purged during Step 2.
2. **Cryptographic Deduplication**: SHA-256 hashes were computed for every image (`data/metadata/dataset_metadata.csv`). Zero cross-split duplicates or cross-class collisions exist.
3. **Partitioning Methodology**:
   - **Train Split (70%)**: 4,035 images (1,989 Real, 2,046 Synthetic)
   - **Validation Split (15%)**: 864 images (426 Real, 438 Synthetic)
   - **Test Split (15%)**: 865 images (427 Real, 438 Synthetic)
   - Splits are strictly stratified across classes and generator types.
